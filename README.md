Полностью завершенный юазовый проект для моего онлайн магазина по продаже вещей. 

Может использовать любую базу данных которую можно указать в settings.py

Возможности веб приложения:

1) Добавление товаров через админ консоль и вывод карточек товара по 9шт на 1 страницу в ПК версии 
и вывод по 5шт на 1 странице в мобильной версии с полноценной пагинацией страниц и четкой системой 
кнопок страниц
    Есть возможность ставить товары в режим "Неактивный"

2) Полноценная мобильная версия всех страниц сайта, коректно отображаеться на 99% устройств разной диагонали и ширины дисплея

3) Внутрення страница самого товара имеет карусель с фотографиями товара
    В ПК версии страницы есть увеличение фотографии при наведении курсора (лупа)
    Страница не перезагружаеться при добавлении товара в корзину выводя сообщение об успешном добавлении в корзину
    Возможность смотреть и добавлять фотографии размерной сетки товаров

5) Корзина подсчитывает количество товара и финальную стоимость для оплаты за все товары в корзине

6) Есть возможность создавать и выводить категории товара для фильтрации по категории

7) Есть счетчик количества товаров в корзине сверху на иконке

8) Форма для создания заказа работает по принципу отсылания заполненой формы пользователем на электронную почту через 
сервис EmailJS
    Если товаров нет в корзине страница с созданием заказа будет не доступна
    Если товар помечен как "Неактивный" на страницу такого товара нельзя будет перейти по ссылке

9) В каталоге доступен поиск по названию товара и по буквам

10) Есть подлючение фавикона

11) Проект структурирован по папкам для удобного чтения
